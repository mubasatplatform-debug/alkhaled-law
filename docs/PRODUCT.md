# الفكرة

**المحامي خالد العنزي** منصة تشغيل لمكتب محاماة سعودي واحد.

العميل لا يملأ نماذج متفرقة ولا يُرسل إلى زووم. يدخل البوابة، يتحدث مع مساعد ذكي (كتابة أو صوت)، يأخذ توجيهاً أولياً، ويُحجز له موعد استشارة مرئية **داخل نفس النظام**. المحامي يستقبل الطلب في لوحة المكتب ويدخل الغرفة من حاسوبه.

```
العميل (الجوال)          المكتب (الحاسوب)
     │                         │
     ├─ تسجيل دخول سهل         ├─ لوحة تشغيل
     ├─ مساعد ذكي + صوت        ├─ مواعيد حيّة من البوابة
     ├─ حجز استشارة            ├─ ملف العميل
     └─ غرفة مرئية WebRTC  ←───┴─ نفس الغرفة (بدون زووم)
```

## لماذا بهذه الطريقة

- مكاتب المحاماة تضيع الوقت بين واتساب والبريد وتقويم خارجي.
- العميل يريد جواباً سريعاً ثم موعداً واضحاً.
- الاستشارة المرئية جزء من الملف، ليست رابطاً ينتهي بعد الجلسة.

## ثلاثة أسطح

| السطح | لمن | ماذا يفعل |
|---|---|---|
| الموقع `/` | الزائر | ثقة، خدمات، دخول |
| بوابة العميل `/portal` | الموكل | مساعد، مواعيد، طلبات، حساب |
| لوحة المكتب `/office` | المحامي والطاقم | مواعيد، عملاء، رسائل، إطلاق |

## ما يعمل اليوم (نواة المنتج)

- تسجيل دخول: Google / X / البريد
- مساعد ذكي يحجز **ويستشير** في نفس المحادثة
- تسجيل صوتي + تفريغ + رد صوتي
- حجز مواعيد على ساعات العمل (أحد–خميس، خانات 30 د)
- مزامنة المكتب ↔ البوابة عبر قاعدة البيانات
- استشارة مرئية WebRTC داخل التطبيق (غرفة = رقم الموعد)
- ثيم احترافي بنفس لغة تمارا البصرية (بنفسجي #9601F1، عناوين كوفي، أزرار حبوب) مع صور مكتب محاماة — بدون استنساخ شعار تمارا
