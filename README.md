# المحامي خالد العنزي

منصة مكتب محاماة سعودي: **بوابة موكل + مساعد ذكي + استشارة مرئية داخل النظام.**

العميل يدخل، يتحدث (كتابة أو صوت)، يأخذ توجيهاً أولياً، ويُحجز له موعد. المحامي يدير الملف من لوحة المكتب ويدخل نفس غرفة الفيديو — بدون زووم وبدون تشتيت بين واتساب والبريد.

> الحالة: **عرض تشغيلي جاهز للتجربة.** الإطلاق على موكلين حقيقيين ينتظر قاعدة إنتاج، TURN للفيديو، ومزوّد رسائل. التفاصيل في [`docs/GAPS.md`](docs/GAPS.md).

## الفكرة

مكتب محاماة صغير لا يحتاج نظام قضايا ضخماً في اليوم الأول. يحتاج:

1. دخول سهل للموكل
2. شخص (أو مساعد) يردّ ويحجز
3. جلسة مرئية تبقى داخل الملف
4. شاشة واحدة للمكتب ترى المواعيد القادمة

هذا ما تبنيه المنصة. التصميم بصري بلغة قريبة من تمارا (بنفسجي كهربائي، عناوين كوفية، حبوب كبيرة) مع صور مكتب محاماة — لا صور أسلوب حياة، ولا استنساخ شعار.

## ما الجاهز وما الناقص

**جاهز**

- مساعد يحجز ويستشير في نفس الخيط، مع تسجيل صوتي
- حجوزات حقيقية في Postgres تظهر في المكتب
- WebRTC داخل التطبيق (غرفة = الموعد)
- ثيم احترافي RTL، جوال أولاً

**ناقص قبل الاعتماد التجاري** — جدول كامل في [`docs/GAPS.md`](docs/GAPS.md)

- Neon ثابت بدل PGLite المؤقت
- خادم TURN للشبكات المغلقة
- SMS / واتساب للتذكير
- رفع مستندات ودفع فواتير (الشاشات تجريبية)
- ربط `app.alkhaledlaw.com`

## التطوير

```bash
npm install
npm run dev          # 0.0.0.0:8080
npm run typecheck
npm run build
```

بدون `DATABASE_URL` تعمل المنصة على PGLite محلي (مناسب للعرض). الإنتاج يحتاج Neon — انظر [`.env.example`](.env.example) و[`docs/LAUNCH.md`](docs/LAUNCH.md).

## الهيكل

شرح موجز في [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md). القاعدة:

- `src/routes/` صفحة = ملف
- `src/lib/` الخادم (حجز، مساعد، صلاحيات)
- `migrations/` مخطط القاعدة
- `public/images/` أصول المكتب فقط
